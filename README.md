# rollcallLMS-offline-secure-LMS-
This is a LMS system used by 8+ schools and 1000+ students on a daily basis, this system works completely offline and is directly plug and play while ensuring content safety when running on public computers

The database and uploaded files are stored in `pendriveData/`. See [backend/README.md](backend/README.md#data-location) for migration and USB startup instructions.
